# Schema Management

Place your schema management DDL scripts in the `sql` directory.
These scripts will be executed in alphabetical order to set up or modify the database schema as needed. Ensure that your scripts are idempotent and handle any necessary migrations gracefully.
For full details and maning conventions, please refer to the [Schema Management Documentation](https://dev.azure.com/MilwaukeeToolData/Supply%20Chain%20Analytics/_wiki/wikis/Data%20Platform%20Documentation/1560/Schema-Management).
